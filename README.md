# Task Us - A Dynamic Task Management System

## Overview 📌  
**Task Us** is an easy-to-use task management system designed to help teams work together more effectively and stay organized. It simplifies the process of tracking tasks, ensuring that both managers and team members can easily see what's due and what's in progress. The system streamlines task management, enabling seamless collaboration and improved productivity.

![Logo](Overview.png)

## Features 📌

### Admin Features  
- **Dashboard**: Provides an overview of tasks and performance analytics.  
- **Task Management**:  
  - Create, update, and delete tasks.  
  - Track task progress and assign tasks to team members.  
- **Review**:  
  - View completed tasks and decide whether to approve or request revisions.  
- **Task History**: Keep a record of all approved tasks, from past to present.  
- **Member Management**: Activate or deactivate user accounts.  

### User Features  
- **Dashboard**: Displays an overview of assigned tasks and progress.  
- **Task Management**:  
  - View assigned tasks and track their progress.  
  - Task priority indicators:  
    - 📌 Assigned tasks.  
    - 🟥🟥🟥🟥🟥 High-priority tasks.  
    - 🟨🟨🟨🟨🟨 Medium-priority tasks.  
    - 🟩🟩🟩🟩🟩 Low-priority tasks.  

### Authentication  
- **Login/Logout**: Secure login and logout functionality for users.

## Tech Stack 📌  
- **Frontend**: HTML (Blade templating), CSS, Bootstrap, JavaScript, Alpine.js  
- **Backend**: PHP (Laravel)  
- **Database**: MySQL
